# Culinary

A browser-based recipe book. Recipes and reviews are stored in the current
browser's `localStorage` and are not synchronized between devices.

## Run locally

1. Install dependencies with `npm install`.
2. Build the TypeScript sources with `npm run build`.
3. Serve this directory on `localhost` using a local static web server and open
   `index.html`.

The application entry point is `src/main.ts`; the build outputs browser modules
to `dist/`.
